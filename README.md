# Predict Fun Bot 🤖

MVP бот на Python для роботи з Predict Fun API.

## 📋 Функціональність

- ✅ Автоматичний пошук активних ринків з cursor-based pagination (до 750 ринків)
- ✅ **Пошук ринку за назвою або slug** для швидкого знаходження потрібного маркету
- ✅ Отримання списку доступних ринків (markets)
- ✅ Перегляд публічної книги ордерів (orderbook) для будь-якого ринку
- ✅ **Моніторинг в реальному часі через WebSocket** - мгновенні оновлення без затримок
- ✅ **Моніторинг через polling** з автооновленням (альтернатива WebSocket)
- ✅ Фільтрація активних/завершених ринків
- ✅ Вибір конкретного ринку через CLI аргументи
- ✅ Безпечне зберігання API ключа в `.env` файлі
- ✅ Зручне відображення інформації про ордери купівлі та продажу
- ✅ Автоматичне переподключення WebSocket з exponential backoff
- ✅ Режими дебагу та verbose для діагностики

## 🚀 Встановлення

1. **Клонуйте репозиторій або завантажте файли**

2. **Встановіть залежності:**
```bash
pip install -r requirements.txt
```

3. **Налаштуйте API ключ:**

Створіть файл `.env` в кореневій директорії проекту:
```bash
cp .env.example .env
```

Відредагуйте файл `.env` та додайте ваш API ключ:
```
API_KEY=ваш_апі_ключ_тут
```

> **Як отримати API ключ:**
> 1. Приєднайтесь до Discord серверу Predict.fun
> 2. Відкрийте тікет підтримки
> 3. Запросіть API ключ для mainnet

## 💻 Використання

### Основний режим (автоматично знайде активний ринок)
```bash
python predict_bot.py
```
> Бот автоматично шукає активні ринки, використовуючи pagination (до 5 сторінок по 150 ринків = 750 ринків максимум).

### Перегляд списку активних ринків
```bash
python predict_bot.py --list-markets
```

### Перегляд всіх ринків (включно із завершеними)
```bash
python predict_bot.py --list-markets --show-all
```

### Отримання книги ордерів для конкретного ринку
```bash
python predict_bot.py --market-id <MARKET_ID>
```

### Пошук ринку за назвою
```bash
# Пошук за частиною назви
python predict_bot.py --search "BTC/USD 11:30"

# Пошук за slug
python predict_bot.py --search "btc-usd-11-30"

# Пошук серед всіх ринків (включно із завершеними)
python predict_bot.py --search "BTC" --show-all --limit 100
```

### Моніторинг orderbook в реальному часі

#### 🔌 WebSocket моніторинг (рекомендовано)
```bash
# Real-time оновлення через WebSocket
python predict_bot.py --market-id <MARKET_ID> --websocket

# Автоматичний вибір активного ринку
python predict_bot.py --websocket

# З debug логами для діагностики
python predict_bot.py --market-id <MARKET_ID> --websocket --debug
```
> **Переваги WebSocket:**
> - Мгновенні оновлення при зміні orderbook
> - Менше навантаження на API (немає постійних запитів)
> - Автоматичне переподключення при розриві з'єднання
> - Heartbeat механізм для підтримки стабільного з'єднання

#### 📊 Polling моніторинг (альтернатива)
```bash
# Оновлення кожні 10 секунд через HTTP polling
python predict_bot.py --market-id <MARKET_ID> --watch 10

# Автоматичний вибір активного ринку з оновленням кожні 5 секунд
python predict_bot.py --watch 5
```

> Натисніть `Ctrl+C` для зупинки моніторингу в обох режимах

### Детальна інформація про ринки (outcomes, tokenId)
```bash
python predict_bot.py --list-markets --verbose
```

### Зміна кількості ринків у списку
```bash
python predict_bot.py --list-markets --limit 20
```

### Режим дебагу (повна JSON структура)
```bash
python predict_bot.py --debug
```

### Довідка по командам
```bash
python predict_bot.py --help
```

### Зробити файл виконуваним
```bash
chmod +x predict_bot.py
./predict_bot.py --list-markets
```

## 🔧 Технічні деталі

### API Endpoints

#### REST API
- `GET /v1/markets` - отримання списку доступних ринків
- `GET /v1/markets/{marketId}/orderbook` - отримання книги ордерів для конкретного ринку

#### WebSocket API
- `wss://ws.predict.fun/ws?apiKey=<YOUR_KEY>` - WebSocket підключення для real-time оновлень
- **Topic:** `predictOrderbook/{marketId}` - підписка на оновлення orderbook конкретного ринку
- **Features:**
  - Автоматичний heartbeat механізм (кожні 15 секунд)
  - Автоматичне переподключення при розриві з exponential backoff
  - Підтримка множинних підписок
  - JSON формат повідомлень

### Аутентифікація

Для доступу до публічних ендпоінтів використовується тільки API ключ, який передається в заголовку:
```
x-api-key: your_api_key
```

> **Примітка:** Для отримання особистих ордерів користувача потрібна додаткова JWT аутентифікація через приватний ключ гаманця. Ця функція може бути додана в майбутніх версіях.

### Залежності

- `requests >= 2.31.0` - для HTTP запитів до API
- `python-dotenv >= 1.0.0` - для роботи з `.env` файлами
- `websocket-client >= 1.7.0` - для WebSocket підключення в реальному часі

### CLI Аргументи

- `--list-markets` - показати тільки список активних ринків
- `--show-all` - показати всі ринки, включно із завершеними (RESOLVED)
- `--market-id <ID>` - вибрати конкретний ринок для перегляду
- `--search <QUERY>` - **пошук ринку за назвою або slug** (наприклад, "BTC/USD 11:30")
- `--websocket` - **моніторинг через WebSocket** для мгновенних оновлень orderbook (рекомендовано)
- `--watch <SECONDS>` - **моніторинг через polling** з вказаним інтервалом оновлення (альтернатива WebSocket)
- `--limit <N>` - обмежити кількість ринків у списку (за замовчуванням: 10, вимикає автопошук)
- `--verbose` - показати детальну інформацію про ринки (outcomes, tokenId, статус)
- `--debug` - показати повну JSON структуру ринку та WebSocket логи для діагностики
- `--help` - показати довідку по всіх доступних командах

**Примітки:**
- За замовчуванням бот автоматично шукає активні ринки через pagination (до 750 ринків)
- Завершені ринки (RESOLVED) не мають активної книги ордерів
- При використанні `--limit` автоматичний пошук з pagination вимикається
- API дозволяє максимум 150 ринків за один запит
