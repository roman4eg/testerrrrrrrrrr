# Predict Fun Bot 🤖

MVP бот на Python для роботи з Predict Fun API.

## 📋 Функціональність

- ✅ Отримання списку активних ордерів
- ✅ Безпечне зберігання API ключа в `.env` файлі
- ✅ Зручне відображення інформації про ордери

## 🚀 Встановлення

1. **Клонуйте репозиторій або завантажте файли**

2. **Встановіть залежності:**
```bash
pip install -r requirements.txt
```

3. **Налаштуйте API ключ:**

Створіть файл `.env` в кореневій директорії проекту:
```bash
cp .env.example .env
```

Відредагуйте файл `.env` та додайте ваш API ключ:
```
API_KEY=ваш_апі_ключ_тут
```

> **Як отримати API ключ:**
> 1. Приєднайтесь до Discord серверу Predict.fun
> 2. Відкрийте тікет підтримки
> 3. Запросіть API ключ для mainnet

## 💻 Використання

Запустіть бота:
```bash
python predict_bot.py
```

Або зробіть файл виконуваним:
```bash
chmod +x predict_bot.py
./predict_bot.py
```

## 🔧 Технічні деталі

### API Endpoints

Бот використовує наступні ендпоінти:
- `GET /v1/orders` - отримання активних ордерів

### Аутентифікація

Для аутентифікації використовується API ключ, який передається в заголовку:
```
x-api-key: your_api_key
```

### Залежності

- `requests` - для HTTP запитів до API
- `python-dotenv` - для роботи з `.env` файлами
