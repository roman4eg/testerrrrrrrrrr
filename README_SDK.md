## 🔑 Налаштування для створення ордерів

### Необхідні компоненти:

1. **JWT токен** - для аутентифікації запитів до API
2. **Приватний ключ гаманця** - для криптографічного підпису ордерів
3. **Predict SDK** - встановлюється автоматично через requirements.txt

### Додайте в файл `.env`:

```env
API_KEY=ваш_api_key
JWT=ваш_jwt_токен  
PRIVATE_KEY=0x...ваш_приватний_ключ...
```

### ⚠️ ВАЖЛИВО - БЕЗПЕКА:

- **НІКОЛИ** не діліться приватним ключем
- Не комітьте `.env` файл в git (він вже в .gitignore)
- Приватний ключ дає повний доступ до вашого гаманця

### Як отримати приватний ключ:

**MetaMask:**
1. Відкрийте MetaMask
2. Settings → Security & Privacy  
3. Reveal Private Key
4. Введіть пароль
5. Скопіюйте ключ (починається з `0x`)

**Trust Wallet / інші:**
- Шукайте опцію "Export Private Key" або "Backup Private Key"

**Формат:** `0x` + 64 hex символи

Приклад: `0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef`

### Чому потрібен приватний ключ?

Predict Fun використовує криптографічні підписи для ордерів. Кожен ордер:
1. Будується з параметрами (ціна, кількість, токен)
2. Хешується
3. Підписується вашим приватним ключем
4. Відправляється на сервер з підписом

Це забезпечує, що тільки власник гаманця може створювати ордери від свого імені.
